Como usar

  • Importe LoadingComponent de creamy-kit.
  • Use icon para o ícone central (nome do SVG sem extensão). Default: circle_variant.
  • Use size: xsmall, small, medium (padrão) ou large.
  • Use variant: primary (azul, padrão), neutral (escuro) ou on-brand (branco, para fundos coloridos).
  • Use [showIcon]="false" para exibir apenas o radial de traços.
  • Os 8 traços percorrem a volta como uma cauda de cometa — animação automática.
