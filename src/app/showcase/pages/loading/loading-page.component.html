Como usar

  • Importe LoadingComponent de creamy-kit.
  • Tamanhos: xsmall (16px), small (24px), medium (32px), large (64px), xlarge (128px).
  • Variantes: primary (azul), neutral (cinza), on-brand (branco).
  • Ícone: use icon para o ícone central (nome do SVG). Default: circle_variant.
  • Sem ícone: use [showIcon]="false" para mostrar apenas o radial de traços.
  • Os 8 traços animam como uma cauda de cometa — rotação contínua.
