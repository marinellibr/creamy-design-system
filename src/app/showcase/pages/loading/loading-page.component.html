Como usar

  • Importe LoadingComponent de creamy-kit.
  • Use size para controlar o tamanho: small, medium (padrão), ou large.
  • Use variant para a cor: default (azul, padrão) ou subtle (cinza).
  • O spinner é animado automaticamente — perfeito para indicar carregamento.
