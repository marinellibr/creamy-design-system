Como usar

  • Importe RadioComponent de creamy-kit.
  • Passe options com um array de {{ '{' }} label, value {{ '}' }}.
  • Use [(ngModel)] ou formControl para vincular o valor (tipo string, seleção única).
  • Opcionalmente, passe color (CSS var ou valor direto) para colorir ambos os ícones (base e variant).
  • Default: sem color, usa radio_button_base cinza e radio_button_variant azul.
  • Com color: ambos os ícones usam a mesma cor.
  • [disabled] — bloqueia interação e aplica estilo desabilitado.
  • Espaço fixo de 12px entre o ícone e a label.
