Checkbox

Recebe [options] ({{ '{' }} label, value {{ '}' }}[]) e renderiza uma linha por opção: quadrado à esquerda (Action/neutral/base → Action/primary/base quando marcado) e um divider abaixo — consumindo o kit-divider.

  • [options] — array de {{ '{' }} label, value {{ '}' }}
  • [divider] — exibe o divider abaixo de cada opção (default true)

Implementa ControlValueAccessor (valor = string[]).
