Como usar

  • Importe TextComponent de creamy-kit.
  • Use o componente <creamy-kit-text> com os inputs:
  • type: 'title' | 'subtitle' | 'section' | 'body' | 'label'
  • size: depende do type (veja exemplos acima)
  • color (opcional): 'default' | 'on-brand' | 'variant' (section não tem variant)
  • bold (opcional): true para weight 500 em body e label
  • underline (opcional): true para underline em label
