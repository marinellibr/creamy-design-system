Como usar

  • Importe TabBarComponent e TabBarItemComponent de creamy-kit.
  • Use <creamy-kit-tab-bar> como container.
  • Dentro, adicione <creamy-kit-tab-bar-item> para cada aba.
  • Inputs do TabBarItem:
    • icon — nome do ícone (obrigatório, 24px, branco)
    • label — texto opcional abaixo do ícone (12px, cor #484848)
    • value — identificador para a seleção (obrigatório)
  • Use [(ngModel)] ou formControl para vincular a seleção (tipo string).
  • Estilo: altura 74px, 100% largura, border-radius 24px topo, fundo azul (#128cfe).
  • Posição: fixed na base da viewport, z-index 100.
