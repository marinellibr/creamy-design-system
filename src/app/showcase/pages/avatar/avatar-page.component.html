kit-avatar-icon · kit-avatar-text · kit-avatar-image

Cada tipo de avatar é um componente próprio:

  • kit-avatar-icon — input name (ícone)
  • kit-avatar-text — input text (iniciais)
  • kit-avatar-image — inputs src / alt

size

Type: 'small' | 'medium' | 'large'

Default: 'medium' — 24 / 32 / 48 px

contrast

Type: 'dark' | 'light' | 'variant' | 'on-brand'

Default: 'dark'

percentage

Type: number · Default: 0

Acima de 0 (até 100) desenha um anel de progresso ao redor do avatar.
